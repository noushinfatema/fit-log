Project NAme : FitLog - A gym companion

Project Description : 
A modern, dark-themed gym companion web application built with **Next.js** and **Tailwind CSS**. FitLog allows users to explore workout libraries, lock exercises into today's plan, track exercise metrics live, and organize their workout routines seamlessly.

Technologies Used : 

-Framework:[Next.js](https://nextjs.org/) (App Router)
-Styling: [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
-Language:TypeScript
-State Management: React Context API & `localStorage`
-Notifications: [React Hot Toast](https://react-hot-toast.com/)

5 Key Features :

1. Workout Library Grid: Displays an interactive grid of 12 exercises covering major muscle groups with dynamic details fetched directly from the REST API.
2. Dynamic Status Counters: Real-time "Plan" and "Saved" status badges in the navbar that automatically update as items are added or removed.
3. Live Metrics Dashboard: Automatically calculates and displays total exercises, total duration (minutes), and total calories burned on the "My Plan" dashboard.
4. Dynamic List Sorting: Allows users to sort their planned and saved workouts on the fly by Duration, Calories, or Rating.
5. Interactive Actions & Toasts: Supports "Mark as Done" completion tracking and item removal with instant visual toast notifications.
